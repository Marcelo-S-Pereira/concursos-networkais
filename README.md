# APP Concursos

APP Concursos é uma plataforma de estudos para concursos públicos. O sistema
organiza cadernos de questões, simulados, revisão de desempenho e apoio por IA
para ajudar o estudante a treinar com base em provas e gabaritos.

## Para Que Serve

- transformar materiais de estudo em cadernos de questões;
- responder simulados e acompanhar desempenho;
- revisar erros e pontos fracos;
- usar explicações assistidas por IA durante o estudo;
- organizar conteúdos, prompts e recursos de apoio em uma interface web.

## Como Usar

1. Cadastre-se ou acesse sua conta.
2. Crie ou importe um caderno de estudo.
3. Responda questões no modo treino ou simulado.
4. Acompanhe estatísticas de acerto, revisão e evolução.
5. Use o chat/tutor de estudo para pedir explicações e reforçar temas difíceis.

## Observação

Este repositório contém somente o código e a estrutura do projeto. Dados reais,
credenciais, chaves, arquivos privados e bases preenchidas não fazem parte do
repositório.
